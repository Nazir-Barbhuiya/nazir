# images/

Drop any images you want to reference from `index.html` here, e.g.:

- `avatar.jpg` — a headshot or avatar, if you want to add one to the hero or about section
- `og-image.png` — a social preview image (1200×630) if you add Open Graph tags later
- project screenshots, if you want thumbnails on the project cards in the "log" section

`favicon.svg` is already here and wired up in `index.html`.
