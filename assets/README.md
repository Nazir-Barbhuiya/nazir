# assets/

Put downloadable files here, e.g.:

- `resume.pdf` — your resume. The hero section already links to `assets/resume.pdf`,
  so drop a file with that exact name here and the link will work as-is.

Anything else you want people to download (a one-pager, a case study PDF, etc.)
can also live in this folder — just link to it as `assets/filename.ext` from `index.html`.
